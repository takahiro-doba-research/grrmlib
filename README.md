# grrmlib

Python utilities for handling molecular structures and reaction path data
generated by **GRRM** and **Gaussian**.

- Read and write GRRM / Gaussian / xyz files
- `Molecule` and dictionary-like `Molecules` containers
- Geometry operations (distances, dihedral angles, fragment separation, overlay, rotation)
- Reaction path networks built on `networkx`
- Pipelines for separating AFIR products into fragments, writing them as xyz files and making Gaussian SP / GRRM MIN inputs

Functions fall into four kinds: file → core (`read_xxx`), core → file (`write_xxx`),
core → core (geometry and `operations`), and file → file (`pipelines`, which chain the other three).
Running the calculations (Gaussian, GRRM, parallelization, job submission) is left to bash / Slurm.

> [!WARNING]
> Only tagged versions are guaranteed to work (see [Tags](https://github.com/takahiro-doba-research/grrmlib/tags)).
> Untagged commits, including the latest `main`, are under development: they may not work, and the API may change without notice.
> The API differs between versions, so refer to the README of the tag you use.

## Installation

Check out a tagged version, then build the environment with Docker.

```bash
git clone https://github.com/takahiro-doba-research/grrmlib.git
cd grrmlib
git checkout <tag>
docker compose build
docker compose run --rm app python your_script.py
```

The repository is mounted at `/work` and `src/` is on `PYTHONPATH`, so code changes take effect without rebuilding.
Dependencies are listed in `requirements.txt` (Python 3.13).

## Molecule and Molecules

`Molecule` holds a single structure. Attribute names follow [cclib](https://cclib.github.io/data.html)
(`charge`, `mult`, `symbols`, `atomcoords`, `scfenergy`, `zpve`, `nmeigen`, ...).
Atoms are identified by 1-based `labels`, which are kept when atoms are selected or removed.
Energies are in Hartree and coordinates in Å.

`Molecules` is a dictionary mapping keys (int or tuple) to `Molecule`.

```python
import grrmlib as gl

eqs = gl.read_eq_list("EQ_list.log")   # keys are the EQ numbers: 0, 1, 2, ...
pts = gl.read_pt_list("TS_list.log")   # also works for PT_list.log

eq = eqs[0]
eq.scfenergy, eq.afirenergy, eq.zpve, eq.mult
pts[0].connection                       # e.g. (0, 1) or (0, "??")

eqs.filter(lambda eq: eq.scfenergy < -152.75)
eqs.smallest("scfenergy")
eqs.largest("scfenergy")
eqs.map(lambda eq: eq.reset_labels())

eq.select_atoms([1, 2, 3])              # by label
eq.remove_atoms([1])
```

## Geometry

```python
gl.get_distance(eq, 1, 2)                       # labels, not indices
gl.get_dihedral_angle(eq, 2, 1, 4, 5, degrees=True)
gl.get_distance_matrix(eq)
gl.get_adj_matrix(eq)                           # bonded if distance < 1.25 * sum of covalent radii
gl.rotate(eq, 1, 4, 90, degrees=True)           # returns new coordinates (rotation about the 1-4 axis)
gl.overlay(eq0, eq1, 1, 2, 3, 1, 2, 3)          # coordinates of eq1 overlaid on eq0
```

### Separating fragments and grouping

```python
frags = gl.separate(eq)                         # Molecules {0: fragment, 1: fragment, ...}

# All fragments of all EQs, keyed by (EQ, fragment)
frags = eqs.expand(gl.separate).flatten()

# Group identical fragments (same labels, symbols and bonding topology)
groups = frags.cluster(gl.is_identical)         # GroupedMolecules {group: Molecules}
unique = groups.flatten().reset_keys()

# Every chemically valid (charge, mult) combination
gl.product_charge_mult(frags[(0, 0)], [-1, 0, 1], [1, 2])
```

## Reading and writing files

| Format | Read | Write |
|---|---|---|
| Gaussian input | `read_gaussian_input(s)` | `write_gaussian_input(s)` |
| Gaussian output (via cclib) | `read_gaussian_output(s)` | `write_gaussian_scan` (GaussView-readable pseudo scan) |
| GRRM input | `read_grrm_input(s)` | `write_grrm_input(s)` |
| GRRM MIN output | `read_grrm_min_output(s)` | |
| GRRM EQ_list / TS_list / PT_list | `read_eq_list`, `read_pt_list` | |
| xyz (`record=True` writes charge, mult and labels as JSON in the title line) | `read_xyz(s)` | `write_xyz(s)` |
| connectable (Gaussian input with extra columns) | `read_connectable(s)` | `write_connectable(s)` |

The plural functions read or write one file per molecule in a folder tree built from the keys.

```python
mols = gl.Molecules({(1, 2): mol_a, (1, 3): mol_b})

# calc/1/2/sp.com, calc/1/3/sp.com
gl.write_gaussian_inputs(
    mols, "calc", "sp.com",
    link0=["%NProcShared=8", "%Mem=8GB"],
    route=["# B3LYP/6-31G(d)"],
)

# calc/SG=1/SEQ=2/sp.com, ... (named folders)
gl.write_gaussian_inputs(mols, "calc", "sp.com", prefixes=["SG", "SEQ"])

# Keys are recovered from the folder names: {(1, 2): ..., (1, 3): ...}
mols = gl.read_gaussian_inputs("calc", "sp.com")

# Skip files that cannot be parsed (e.g. crashed jobs) instead of raising
logs = gl.read_gaussian_outputs("calc", "sp.log", ignore_errors=True)

# Table of attributes (polars DataFrame)
df = gl.to_dataframe(logs, ["SG", "SEQ"], ["scfenergy", "success"])

# Trajectory viewable in GaussView
gl.write_gaussian_scan(eqs, "EQ_list_gv.log")
```

Writers refuse to overwrite existing files unless `overwrite=True` is given.

## Reaction path network

`ReactionPathNetwork` is a `networkx.MultiGraph` with EQs as nodes and PTs as edges,
so all `networkx` functions can be used directly.

```python
import networkx as nx

rpn = gl.ReactionPathNetwork(eqs=eqs, pts=pts)
rpn.remove_eq("??")                     # PTs connected to unknown EQs
rpn.pts_between(12, 15)                 # Molecules of PTs connecting EQ12 and EQ15
nx.shortest_path(rpn, 12, 15)

# Group EQs and merge the PTs between groups
grpn = rpn.cluster(lambda eq0, eq1: ...)   # predicate deciding whether two EQs belong together
grpn.eqs_of_group(0)
grpn.group_of_eq(12)
grpn.pts_between(0, 1)
```

## Pipelines (file → file)

Each pipeline reads files, transforms the molecules and writes files. All paths are given as arguments.

### Separation

```python
import grrmlib as gl

# EQs are separated into fragments, duplicates are grouped, and xyz files are written
# for every valid charge and multiplicity: separation/SG=*/SEQ=*/charge=*/mult=*/seq.xyz.
# The title line holds charge, mult and labels as JSON. Returns the G / EQ / SEQ / SG table.
gl.eq_list_to_xyzs(
    "EQ_list.log", "separation", "separation.csv",
    charges=[-1, 0, 1], mults=[1, 2],
)

# Gaussian inputs next to each xyz: separation/SG=*/SEQ=*/charge=*/mult=*/gaussian_sp.com.
# link0 (without %Chk), route and title are taken from the template.
gl.xyzs_to_gaussian_inputs("separation", "seq.xyz", "template_sp.com")

# ... run Gaussian with bash / Slurm ...

gl.collect_gaussian_outputs(
    "separation", "gaussian_sp.log", "gaussian_sp.csv", key_names=gl.SEPARATION_KEYS,
)

# Most stable SEQ of each SG / charge / mult (failed jobs are ranked last)
gl.gaussian_sp_to_grrm_min(
    "gaussian_sp.csv", "separation", "template_min.com", "gaussian_sp_selected.csv",
    key_names=gl.SEPARATION_KEYS, group_by=["SG", "charge", "mult"],
)

# ... run GRRM with bash / Slurm ...

gl.collect_grrm_min_outputs(
    "separation", "grrm_min.log", "grrm_min.csv", key_names=gl.SEPARATION_KEYS,
)
```

The core → core step is also available on its own:

```python
seqs, table = gl.separate_eqs(eqs)          # seqs keyed by (SG, SEQ)
df = gl.select_lowest(df, ["SG", "charge", "mult"], by="scfenergy")
```

### Connection

```python
gl.connectables_to_gaussian_sp("seq", ["arene", "alkene"], "template_sp.com", "connection")
keys = gl.connection_keys("seq", ["arene", "alkene"])                    # folder names
group_by = gl.connection_keys("seq", ["arene", "alkene"], with_angles=False)
```

## Workflows

`workflows` chains the pipelines into the steps used to compute energy descriptors from SC-AFIR results
(separation → SP → selection → optimization → charges → substituents → ...). Each function corresponds to one script of a project;
everything project-specific (paths, result file names, substituent names) is passed as arguments.
The calculations themselves are not included: run them with any program and write each result next to its input as an xyz file
whose title line is a JSON dict with `charge`, `mult`, `scfenergy` and `success` (and `optsteps` for optimizations).

```python
import grrmlib as gl

keys = gl.SEPARATION_KEYS

gl.make_separation_sp("EQ_list.log", "separation/sp", "separation/separation.csv", charges=[-1, 0, 1], mults=1)
# ... compute separation/sp/SG=*/SEQ=*/charge=*/mult=*/init.xyz and write result.xyz next to each ...
gl.select_sp("separation/sp", "result.xyz", "separation/sp.csv", "separation/sp_selected.csv",
             key_names=keys, group_by=["SG", "charge", "mult"])
gl.make_opt("separation/sp_selected.csv", "separation/sp", "separation/opt", key_names=keys)
# ... optimize separation/opt/.../init.xyz and write result.xyz ...
# Charges of the fragments of each group: total charge 0, lowest sum of energies
gl.select_opt("separation/opt", "result.xyz", "separation/separation.csv", "separation/opt.csv", "separation/opt_selected.csv",
              key_names=keys)

# Substituents (templates raw/arene/0.com, ...) on the optimized structures; folder names give the substituent names
subs = ["arene", "backbone"]
gl.make_connection_sp("separation/sp_selected.csv", "separation/opt", "result.xyz", "note.com",
                      [f"raw/{s}" for s in subs], "connection/sp")
keys = gl.connection_key_names(subs)
# ... SP, select_sp (group_by=gl.SEPARATION_KEYS + subs), make_opt and optimization as above ...
gl.select_opt("connection/opt", "result.xyz", "separation/separation.csv", "connection/opt.csv", "connection/opt_selected.csv",
              key_names=keys, substituents={"arene": [0], "backbone": [0, 1, 2]})
gl.sum_energies("connection/opt_selected.csv", "energy_long.csv", "energy.csv", substituents=subs)
```
