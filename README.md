# grrmlib

This package provides lightweight Python classes and utilities for handling
molecular structures and reaction path data generated by **GRRM** and related
quantum chemical calculations.

It is designed to:
- Represent equilibrium structures (EQ) and transition states (PT)
- Store energies, geometries, vibrational data, and connectivity
- Group molecules based on molecular graph topology
- Filter and select molecular structures based on geometric or energetic criteria
- Read GRRM-style EQ/PT list files into structured Python objects

---

## Features

- Object-oriented representation of molecules (`Molecule`, `EQ`, `PT`)
- Container classes for molecule collections (`Molecules`, `EQs`, `PTs`)
- Automatic grouping by adjacency matrix (graph isomorphism–like behavior)
- Distance-based filtering of molecular structures
- Convenient access to minimum / maximum structures by any attribute
- Parsers for GRRM EQ list and PT list files
- Export of molecular geometries to Gaussian input format

---

## Installation

This package has no special installation requirements beyond standard
scientific Python libraries.

Required dependencies:
- GRRM23 developmental version
- Gaussian 16
- Python 3.10+
- jupyterlab 4.0.10
- networkx 3.4.2
- numpy 1.24.2
- scipy 1.10.0
