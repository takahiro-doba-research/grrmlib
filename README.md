# grrmlib

Python utilities for handling molecular structures and reaction path data
generated by **GRRM** and **Gaussian**.

- Read and write GRRM / Gaussian / xyz files
- `Molecule` and dictionary-like `Molecules` containers
- Geometry operations (distances, dihedral angles, fragment separation, overlay, rotation)
- Reaction path networks built on `networkx`
- Workflow for separating AFIR products into fragments and setting up Gaussian SP / GRRM MIN jobs
- Batch SP / geometry optimization with any ASE calculator

> [!WARNING]
> Only tagged versions are guaranteed to work (see [Tags](https://github.com/takahiro-doba-research/grrmlib/tags)).
> Untagged commits, including the latest `main`, are under development: they may not work, and the API may change without notice.
> The API differs between versions, so refer to the README of the tag you use.

## Installation

Check out a tagged version, then build the environment with Docker.

```bash
git clone https://github.com/takahiro-doba-research/grrmlib.git
cd grrmlib
git checkout <tag>
docker compose build
docker compose run --rm app python your_script.py
```

The repository is mounted at `/work` and `src/` is on `PYTHONPATH`, so code changes take effect without rebuilding.
Dependencies are listed in `requirements.txt` (Python 3.13, CPU build of PyTorch).

## Molecule and Molecules

`Molecule` holds a single structure. Attribute names follow [cclib](https://cclib.github.io/data.html)
(`charge`, `mult`, `symbols`, `atomcoords`, `scfenergy`, `zpve`, `nmeigen`, ...).
Atoms are identified by 1-based `labels`, which are kept when atoms are selected or removed.
Energies are in Hartree and coordinates in Å.

`Molecules` is a dictionary mapping keys (int or tuple) to `Molecule`.

```python
import grrmlib as gl

eqs = gl.read_eq_list("EQ_list.log")   # keys are the EQ numbers: 0, 1, 2, ...
pts = gl.read_pt_list("TS_list.log")   # also works for PT_list.log

eq = eqs[0]
eq.scfenergy, eq.afirenergy, eq.zpve, eq.mult
pts[0].connection                       # e.g. (0, 1) or (0, "??")

eqs.filter(lambda eq: eq.scfenergy < -152.75)
eqs.smallest("scfenergy")
eqs.largest("scfenergy")
eqs.map(lambda eq: eq.reset_labels())

eq.select_atoms([1, 2, 3])              # by label
eq.remove_atoms([1])
```

## Geometry

```python
gl.get_distance(eq, 1, 2)                       # labels, not indices
gl.get_dihedral_angle(eq, 2, 1, 4, 5, degrees=True)
gl.get_distance_matrix(eq)
gl.get_adj_matrix(eq)                           # bonded if distance < 1.25 * sum of covalent radii
gl.rotate(eq, 1, 4, 90, degrees=True)           # returns new coordinates (rotation about the 1-4 axis)
gl.overlay(eq0, eq1, 1, 2, 3, 1, 2, 3)          # coordinates of eq1 overlaid on eq0
```

### Separating fragments and grouping

```python
frags = gl.separate(eq)                         # Molecules {0: fragment, 1: fragment, ...}

# All fragments of all EQs, keyed by (EQ, fragment)
frags = eqs.expand(gl.separate).flatten()

# Group identical fragments (same labels, symbols and bonding topology)
groups = frags.cluster(gl.is_identical)         # GroupedMolecules {group: Molecules}
unique = groups.flatten().reset_keys()

# Every chemically valid (charge, mult) combination
gl.product_charge_mult(frags[(0, 0)], [-1, 0, 1], [1, 2])
```

## Reading and writing files

| Format | Read | Write |
|---|---|---|
| Gaussian input | `read_gaussian_input(s)` | `write_gaussian_input(s)` |
| Gaussian output (via cclib) | `read_gaussian_output(s)` | `write_gaussian_scan` (GaussView-readable pseudo scan) |
| GRRM input | `read_grrm_input(s)` | `write_grrm_input(s)` |
| GRRM MIN output | `read_grrm_min_output(s)` | |
| GRRM EQ_list / TS_list / PT_list | `read_eq_list`, `read_pt_list` | |
| xyz | `read_xyz(s)` | `write_xyz(s)` |
| connectable (Gaussian input with extra columns) | `read_connectable(s)` | `write_connectable(s)` |

The plural functions read or write one file per molecule in a folder tree built from the keys.

```python
mols = gl.Molecules({(1, 2): mol_a, (1, 3): mol_b})

# calc/1/2/sp.com, calc/1/3/sp.com
gl.write_gaussian_inputs(
    mols, "calc", "sp.com",
    link0=["%NProcShared=8", "%Mem=8GB"],
    route=["# B3LYP/6-31G(d)"],
)

# calc/SG=1/SEQ=2/sp.com, ... (named folders)
gl.write_gaussian_inputs(mols, "calc", "sp.com", prefixes=["SG", "SEQ"])

# Keys are recovered from the folder names: {(1, 2): ..., (1, 3): ...}
mols = gl.read_gaussian_inputs("calc", "sp.com")

# Skip files that cannot be parsed (e.g. crashed jobs) instead of raising
logs = gl.read_gaussian_outputs("calc", "sp.log", ignore_errors=True)

# Table of attributes (polars DataFrame)
df = gl.to_dataframe(logs, ["SG", "SEQ"], ["scfenergy", "success"])

# Trajectory viewable in GaussView
gl.write_gaussian_scan(eqs, "EQ_list_gv.log")
```

Writers refuse to overwrite existing files unless `overwrite=True` is given.

## Reaction path network

`ReactionPathNetwork` is a `networkx.MultiGraph` with EQs as nodes and PTs as edges,
so all `networkx` functions can be used directly.

```python
import networkx as nx

rpn = gl.ReactionPathNetwork(eqs=eqs, pts=pts)
rpn.remove_eq("??")                     # PTs connected to unknown EQs
rpn.pts_between(12, 15)                 # Molecules of PTs connecting EQ12 and EQ15
nx.shortest_path(rpn, 12, 15)

# Group EQs and merge the PTs between groups
grpn = rpn.cluster(lambda eq0, eq1: ...)   # predicate deciding whether two EQs belong together
grpn.eqs_of_group(0)
grpn.group_of_eq(12)
grpn.pts_between(0, 1)
```

## Separation workflow

`SeparationWorkflow` separates the EQs in an EQ_list into fragments, removes duplicates,
and prepares Gaussian SP and GRRM MIN jobs for every valid charge and multiplicity.
The template input files supply the link0 lines (`%Chk` is dropped), route, title and GRRM options.
Jobs are written to `separation/SG=*/SEQ=*/charge=*/mult=*/`.

```python
wf = gl.SeparationWorkflow(
    path_eq_list="EQ_list.log",
    path_gaussian_sp="template_sp.com",   # Gaussian input used as a template
    path_grrm_min="template_min.com",     # GRRM input used as a template
)

wf.write_gaussian_sp(charges=[-1, 0, 1], mults=[1, 2])
wf.list_gaussian_sp()        # writes gaussian_sp.txt (list of inputs)
# ... run Gaussian ...
wf.analyze_gaussian_sp()     # writes gaussian_sp.csv

wf.write_grrm_min()          # most stable SEQ of each SG / charge / mult
wf.list_grrm_min()           # writes grrm_min.txt
# ... run GRRM ...
wf.analyze_grrm_min()        # writes grrm_min.csv
```

## Batch calculations with ASE

`ASEJobRunner` runs SP (`"sp"`) or geometry optimization (`"opt"`) for every molecule with an ASE calculator,
in parallel processes. Each result is saved as `folder/<key>/<task>.xyz`, and molecules that already have a result are skipped,
so an interrupted run can be resumed with the same call.
Molecules need `charge` and `mult`. Results contain `scfenergy` (Hartree), `success`, `status`, `optsteps` and `elapsed`.

```python
from ase.calculators.emt import EMT

import grrmlib as gl
from grrmlib.jobs.ase_job import ASEJobRunner, read_results


def main():
    mols = gl.read_xyzs("structures", "mol.xyz")
    for mol in mols.values():
        mol.charge, mol.mult = 0, 1

    # calc_factory is called once in each worker process
    runner = ASEJobRunner(EMT, nprocs=4, nthreads=1)
    opts = runner.run(mols, "ase", "opt", fmax=0.02, optimizer="LBFGS")
    sps = runner.run(opts, "ase", "sp")


# Required: worker processes are started with "spawn"
if __name__ == "__main__":
    main()
```

`calc_factory` must be picklable: pass a class or a module-level function (use `functools.partial` for arguments), not a lambda.

## Slurm job script (Kyoto University supercomputer)

```python
scheduler = gl.KyotoUnivSlurmScheduler(
    "gaussian_sp", "log/%a.out",
    partition="gr10000a",
    array="0-99",
    commands=["python run.py $SLURM_ARRAY_TASK_ID"],
)
path = scheduler.write("job.sh")    # #SBATCH --rsc p=1:t=8:c=8:m=8G etc.
job_id = scheduler.sbatch(path)
```
