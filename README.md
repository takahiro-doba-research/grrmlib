# grrmlib

This package provides lightweight Python classes and utilities for handling
molecular structures and reaction path data generated by **GRRM** and related
quantum chemical calculations.

## Features

- Parsers for GRRM output files
- Export of molecular geometries to Gaussian / GaussView input format
- Object-oriented representation of molecules (`Molecule`, `EQ`, `PT`)
- Container classes for molecule collections (`Molecules`, `EQs`, `PTs`)
- Geometry and property-based filtering of moleculars
- Automatic grouping by adjacency matrix

## Installation

This package has no special installation requirements beyond standard
scientific Python libraries.

Required dependencies:
- GRRM23
- Gaussian 16
- Python 3.10+
- networkx 3.4.2

## Core Concepts

### Molecule

`Molecule` is the base class representing a single molecular structure.  
The attribute names correspond to the names used in `cclib`.

Stored attributes include:

- Electronic structure information (`functional`, `basis_set`)
- Charge and multiplicity
- Atomic symbols and Cartesian coordinates
- Energies (`SCF`, `AFIR`, `ZPVE`)
- Gradients, Hessian, and normal mode eigenvalues

```python
mol.scfenergy
mol.atomcoords
mol.symbols
```

### Molecules (Container Class)

`Molecules` is a dictionary-like container mapping labels to `Molecule` objects.

It supports:
- Geometry-based filtering
- Attribute-based selection
- Graph-based grouping

```python
mols.filter(lambda pt: pt.zpve < 0.1)
mols.smallest("scfenergy")
```

## Analyzing GRRM Output Files

### Reading EQ list and PT list

Providing a path to `read_eq_list` returns an `EQs` object (a subclass of `Molecules`).  
Providing a path to `read_pt_list` returns an `PTs` object (also a subclass of `Molecules`).  
Each `PT` object includes connectivity information parsed from the GRRM output.

```python
import grrmlib as gl

eqs = gl.read_eq_list("EQ_list.log")
pts = gl.read_pt_list("PT_list.log")
```

### Distance-Based Filtering

Structures can be filtered based on interatomic distances by chaining multiple conditions.

```python
eqs_filtered = (
    eqs
    .distance_shorter(9, 27, 1.5)       # Keep structures where atoms 9 and 27 are closer than 1.5 Å
    .distance_longer(2, 6, 2.0)         # Keep structures where atoms 2 and 6 are farther than 2.0 Å
    .distance_between(2, 27, 1.2, 2.0)  # Keep structures where atoms 2 and 27 are between 1.2 Å and 2.0 Å
)
```

### Selecting Extreme Structures

Any numerical attribute stored in the molecule can be used.

```python
eq_min = eqs.smallest("scfenergy")
pt_max = pts.largest("afirenergy")
```

### Exporting in Gaussian / GaussView Style

Molecular geometries can be exported to Gaussian-style input files.  
Default values are used if metadata is missing.  

```python
eq.to_gv("eq.com")
eqs["EQ1994"].to_gv("EQ1994.com")
pts["PT3090"].to_gv("PT3090.com")
```

The `Molecules` class also provides a method to export files in GaussView-style.

```python
eqs.to_gv("EQ_list_gv.log")
pts.to_gv("PT_list_gv.log")
```

Caution: GaussView indexes structures starting at 1, but GRRM uses 0-based indexing.

### Reaction Path Network

`ReactionPathNetwork` is a wrapper around a `networkx.MultiGraph` that
represents the reaction path network at the **individual molecule level**.

Features:

- Stores EQ nodes and PT edges
- Provides transparent access to `networkx.MultiGraph` methods via `__getattr__`
- Utilities for adding EQs and PTs, removing EQs, and retrieving PTs

```python
rpn = gl.ReactionPathNetwork()

# Add EQ nodes and PT edges
rpn.add_eqs(eqs)
rpn.add_pts(pts)

# Remove a specific EQ node
rpn.remove_eq("EQ??")

# Retrieve PTs connecting two EQs
connecting_pts = rpn.get_pts("EQ12", "EQ15")
```

`to_networkx()` returns the underlying `networkx.MultiGraph` object.

```python
import networkx as nx

nx.shortest_path(rpn.to_networkx(), "EQ12", "EQ15")
```

### Group Network

GroupNetwork is a wrapper around a `networkx.Graph` that represents the reaction path network at the group level, 
where EQs are grouped by topology or other criteria.

Features:

- Groups EQ nodes by `eq.group`
- Aggregates PT edges between groups
- Provides transparent access to `networkx.Graph` methods via `__getattr__`
- Utilities for adding an entire `ReactionPathNetwork` and retrieving grouped EQs and PTs

A Minimum example for creating a group network using `grrmlib`:

```python
import grrmlib as gl

# Read EQ list an PT list
eqs = gl.read_eq_list("EQ_list.log")
pts = gl.read_pt_list("PT_list.log")

# Set a "group" attribute to each EQ
eqs.set_group()

# Create a reaction path network from EQs and PTs
rpn = gl.ReactionPathNetwork()
rpn.add_eqs(eqs)
rpn.add_pts(pts)
rpn.remove_eq("EQ??")

# Create a group network from the reaction path network
gn = gl.GroupNetwork()
gn.add_rpn(rpn)

# Retrieve all EQs in a group
eqs_in_group = gn.get_eqs("G0")

# Retrieve all PTs connecting two groups
pts_between_groups = gn.get_pts("G0", "G1")
```
